# Personal News Intelligence

中文新闻与医学研究情报系统：主动搜索、RSS、PubMed和官方来源共同发现信息，经百川与DeepSeek分工筛选后生成每日简报。默认安全预览，不自动推送。

## 架构
- Tavily Basic Search：主动发现骨科临床研究、骨科全领域AI、医疗AI交叉研究、国内医疗政策、国内外动态及NSFC官方信息。
- PubMed/NCBI：主动检索近30天论文并核验摘要、PMID、DOI；搜索摘要仅作发现线索。
- Baichuan-M3-Plus：骨科临床研究、骨科全领域AI研究筛选与证据复核；单独筛选NSFC官方动态。
- DeepSeek-Flash：国内医疗政策、民生及国内外重大动态。
- Python：采集编排、去重、日期/链接校验、缓存生命周期、搜索预算审计和推送安全控制。
- PushPlus：默认 `push_enabled=false`，不发送真实消息。

## 学术范围
每日骨科临床研究与骨科全领域AI研究合计目标2–3篇。临床覆盖运动医学、关节镜、韧带、半月板、肩肘、足踝、创伤骨科、骨折、脊柱、关节置换、骨肿瘤、骨质疏松、康复及围手术期管理。骨科AI不限于影像，覆盖临床决策支持、诊断/预后预测、精准医疗、手术机器人/导航、康复、步态/可穿戴设备、临床大模型/Agent/RAG、多模态、因果推断、联邦学习、小样本、可解释AI、数字孪生和真实世界数据。运动医学是临床科研重点，不是检索边界；每篇骨科AI研究增加“对运动医学的潜在启发”，明确尚未验证的思路迁移。
最近7天优先、30天补充，重大突破可放宽至90天；区分首次在线、正式出版、数据库收录日期；区分人体/动物/体外、回顾性/前瞻性、预印本/会议摘要/同行评议论文。评价研究设计、样本量、方法学、外部/前瞻验证、临床转化和局限。

## 新闻与NSFC
国内医疗政策、医保、药械监管、医院改革、医疗服务、公共卫生优先核实官方原文。国内外重大科技、社会、经济、公共卫生与国际动态兼顾；普通新闻优先24小时，重大事件最多48小时。NSFC搜索限定基金委官方域名，关注医学科学部H06运动系统、骨科、运动医学、医学AI与交叉研究。区分官方指南、已资助项目和AI归纳趋势；资助导向不等于学术前沿或获批概率。FDA授权不等于NMPA获批。

## 来源
RSS包括MedicalXpress骨科/运动医学/综合医学、npj Digital Medicine、Nature Medicine、中国新闻网、新华网、BBC和Al Jazeera。PubMed设置骨科全领域、骨科AI和医疗AI交叉三个主题，每主题最多20条候选。Tavily使用6个Basic Search主题查询，不请求全文、不承担AI分析。对HTTP 412或反爬拦截的卫健委、药监局、FDA页面保留权威参考，但不假装采集成功。

## 自动缓存清理
所有清理由每日工作流自动执行：
| 数据 | 生命周期 | 处理 |
|---|---:|---|
| 当天搜索临时文件、网页正文、模型中间输出、临时简报副本 | 当天 | 任务结束立即清理专用 `.cache/transient/` |
| 普通缓存（搜索结果、文章页、模型响应、下载文件） | 7天 | 每7天检查一次，仅清理白名单目录中超过7天的文件 |
| 新闻去重URL、论文PMID/DOI索引 | 30天 | 每次运行自动淘汰超过30天记录，旧格式自动迁移 |
| Tavily月度额度统计 | 滚动12个月 | 仅保留月度数字，不保存搜索结果正文 |

清理仅触碰指定缓存目录，不会删除代码、配置、Secrets或去重状态。Actions Cache是跨运行缓存而非永久数据库，平台仍可能按自身策略淘汰。Tavily程序月度预算上限700 credits，达到上限后暂停主动搜索，RSS/PubMed继续运行。使用GitHub Secret `TAVILY_KEY`，不读取或打印密钥，不自动开通付费。

## 手动测试
1. 运行 **Check News Sources** 检查RSS、PubMed和官方网页。
2. 运行 **Daily News Push**，保持 `push_enabled=false`。
3. 检查Tavily候选及credits、PubMed记录、百川筛选/证据复核、NSFC动态和DeepSeek新闻筛选。
4. 检查学术范围、研究类型、发表时间、证据边界及运动医学启发。
5. 检查日志不含完整简报正文或密钥，并检查当天、每周、30天三档清理。
6. 内容稳定后再单独讨论真实推送和定时运行。

当前仅开放 `workflow_dispatch` 手动运行；未配置schedule，真实推送默认关闭。
