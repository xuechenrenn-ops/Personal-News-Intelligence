## 一、可复核的试验设计

参考样本采用模型以外的期刊、PubMed/Crossref 及专业报道。首轮公开检索过程中核实一条文章的 11 月日期只是期号，真正在线发表在 5 月，遂将其设为旧闻反例。冻结参考版本在模型比较启动前提交，分别记录两个开发日期、两个独立留出日期和最终额外的 10 月归档独立日期。第一个留出序列部分研究曾在第一阶段被使用，最终归档集未用于提示词调参。参考集同时包含论文方案、较低优先级但可能合理替代的研究、过时条目、重复、无原文候选。原始参考与准则见同目录的 `reference.json`、`criteria.md`。

固定候选召回分母是技术可取得并进池的目标论文。渠道覆盖另以独立目标清单为分母，检索查询不含目标 PMID、DOI 或精确题名。历史日期按论文真实首发筛选，当前数据库可见的论文在当时未必已经入库，不能将日期限制回放当作实时历史快照或推断全网漏报率。稿件准确性检查区分有误、通过、因证据不足被拦截和正文未生成。

## 四、自动质量控制及开源选择

- 保留原 GitHub Actions、缓存、分两条消息和证据筛选代码。调查 [Metapub](https://github.com/metapub/metapub) 的 Apache-2.0 客户端和内置缓存，[pyEuropePMC](https://github.com/JonasHeinickeBio/pyEuropePMC) 的检索封装，以及第一阶段评估的 TrendRadar、FreshRSS、research-digest。当前缺口集中在特定查询、证据匹配和只读验证。沿用现有 HTTP/RSS 依赖，对 REST API 做局部整合，未引入第三方代理或付费托管，也没有将上游调研视作全面安全审计。
- 程序绑定原始来源标题、发表日期和 DOI/PMID，候选去重，标记稿件过往有效期，排除常见弱关联媒体标题与无证据候选。生成字段要求对应原文证据段；数值、百分数和常用统计术语自动校验；观察性研究的因果表述、研究启发与事实正文分开处理。复核只能否决风险字段，保存机器审核结果，不代写最终稿。
- 仍有实质限制。相同数字存在于原文不足以证明配对和分组无误，否决式复核可能误杀；不同语种和部分来源可能缺失研究局限或机构信息。Crossref 公告显示其 REST 接口的部分撤稿数据同步有延迟，程序只能排除已确认的撤稿标记，无法保证撤稿覆盖。[Crossref 状态](https://status.crossref.org/)
- 维护和复现走守护型 Actions。运行清单用分支提交预留，唯一创建式领取标志阻断重复执行，失败也计入，不自动重试或自动充值。工具返回账户余额变化单独留证；变化受结算时点与精度影响，不能作为正式发票金额。
